# blinkcam

まばたきがシャッターになるページ。カメラに映った自分の顔から MediaPipe Face Landmarker でまばたきを見つけ、まばたきのたびに目のまわりを撮って、番号付きの窓として画面に積む。目を開けていられる間は持続音が張りつめ、まばたきした瞬間にシャッターが鳴る。16枚たまると番号順の格子に並び、また最初から撮り始める。

カメラの映像はブラウザの中だけで使い、どこにも送らない。

ひとりaudio/visual の「blink」（Veo の3人の顔で同じことをする動画の作品）から、カメラで動かす部分を切り出したもの。

## 使い方

```bash
python3 -m http.server
```

`http://localhost:8000/` を開き、「◉ カメラで始める」を押してカメラを許可する。動いている間は「● 30秒録画」で音付きで録れ、「終わる」（または Esc）で表紙に戻る。

`preview.mp4` は表紙の動画（blink の書き出しから11秒、540px、音なし）。
